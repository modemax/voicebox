# Loki fork — Kokoro-only dependency set (KB-0358).
#
# This is sanctioned divergence #1 of 5 (see LOKI-FORK.md). Upstream's
# requirements.txt bundles all 7 TTS engines — git-only deps, a custom
# find-links index, and --no-deps ordering hacks around torch/numpy/
# transformers conflicts. Engine libs are lazy-imported, so installing
# only Kokoro's slice boots the server fine; the other engines simply
# raise ImportError if invoked (they won't be — Loki's voice.yaml only
# routes to kokoro).
#
# Runtime prerequisite (macOS): brew install espeak-ng, then export
#   PHONEMIZER_ESPEAK_LIBRARY=/opt/homebrew/lib/libespeak-ng.dylib
#   ESPEAK_DATA_PATH=/opt/homebrew/share/espeak-ng-data
# The bundled espeakng-loader wheel points at a dead CI build path;
# without these, misaki's G2P fallback crashes (proven 2026-07-09).
